# How to render linear gauges dynamically in ASP.NET MVC Application?

Repository description: This repository demonstrates dynamic rendering of linear gauges in an ASP.NET MVC sample application.

## Project Overview

A concise runnable example that shows how to render linear gauges dynamically in ASP.NET MVC views.

## Features

- Dynamic rendering of linear gauges in MVC views
- Runnable sample solution

## Prerequisites

- Visual Studio 2022

## How to run

1. Checkout the project to a local folder.
2. Open the solution in Visual Studio 2022.
3. Restore NuGet packages by rebuilding the solution.
4. Run the project and open the sample pages.

## Usage & Support

Use the sample views as a starting point. If you encounter issues, confirm package restore and client scripts are loading, then open an issue with reproduction steps.
